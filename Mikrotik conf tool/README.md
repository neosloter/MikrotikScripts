# MikroTik RouterOS v7 — Production Configuration Tool

Интерактивный веб-конфигуратор и генератор боевых скриптов конфигурации (`.rsc`) для оборудования **MikroTik RouterOS v7**.

Разработано в соответствии с лучшими практиками сетевой безопасности и рекомендациями **vasilevkirill.ru** и **mikrotik-training.ru** (Роман Козлов).

---

## 🚀 Быстрый запуск

Конфигуратор полностью автономен, не имеет внешних зависимостей и работает прямо в браузере:

### Способ 1: Открытие в браузере
Просто откройте файл [`index.html`](./index.html) или [`mikrotik-configurator.html`](./mikrotik-configurator.html) в любом веб-браузере (Chrome, Safari, Firefox, Edge).

### Способ 2: Локальный HTTP-сервер
```bash
python3 -m http.server 8080
```
И откройте в браузере: [http://localhost:8080](http://localhost:8080)

## 🛠 Состав модулей конфигуратора

Конфигуратор разделен на 5 независимых модулей с возможностью выборочного или раздельного включения:

### 1. 🛡️ Модуль 1: Firewall (Default-Drop & Custom Chains)
* **Архитектура кастомных цепочек:** разделение трафика на `ISP-Input`, `ISP-Input-Allow` и `Local-Input`. Любые порты открываются только в терминальной цепочке, исключая конфликты порядка правил.
* **Таблица RAW:** отбрасывание некорректных TCP-флагов (NULL, Xmas, SYN-FIN, SYN-RST) и заблокированных IP до Connection Tracker без нагрузки на CPU.
* **FastTrack:** ускорение транзитного трафика `forward` с обходом правил для установленных сессий.
* **NAT:** поддержка `masquerade` для динамических интерфейсов и `src-nat` для статических публичных IP.

### 2. ⚡ Модуль 2: WireGuard Server (Клиенты и Site-to-Site)
* **Две независимые настройки соединений на сервере:**
  1. **Клиентский доступ (RoadWarrior):**
     * Подключение смартфонов и ПК (Windows, macOS, iOS, Android, Linux) со скачиванием и предпросмотром `.conf` файлов.
     * **Клиенты MikroTik:** генерация готового боевого `.rsc` скрипта RouterOS v7 для роутера в роли клиента (интерфейс, пир, маршрутизация Split/Full Tunnel, MSS Clamping).
  2. **Межофисные соединения (Site-to-Site):**
     * Объединение локальных сетей между роутерами MikroTik (LAN-to-LAN маршрутизация).
     * Автоматический расчет `allowed-address` и маршрутов `/ip route` на стороне сервера.
     * Генерация и экспорт полного `.rsc` скрипта для роутера филиала (интерфейс, пир к серверу, маршрут к локальной сети офиса, MSS Clamping и правила Firewall).
* **Генерация ключей Curve25519 (X25519) прямо в браузере:** мгновенная генерация ключевых пар для сервера, клиентов и филиалов без отправки данных во внешнюю сеть.
* **MSS Clamping (1380):** автоматические правила `mangle change-mss` для устранения зависания сайтов из-за PMTU Blackhole.
* **Встроенное модальное окно:** просмотр, копирование и скачивание `.rsc` скриптов и `.conf` файлов в 1 клик.

### 3. 🤖 Модуль 3: Telegram Alerts (Оповещения и Мониторинг)
* **Движок `TgSend`:** отказоустойчивая функция отправки уведомлений на базе `/tool fetch`.
* **URL-encoding:** автоматическое экранирование спецсимволов и переводов строк.
* **Триггеры событий:**
  * Оповещение о перезагрузке роутера с выводом модели, версии и uptime.
  * Монитор безопасности: логирование входов администратора и попыток подбора паролей.
  * Netwatch Failover: оповещение при падении или восстановлении интернет-каналов.
  * DHCP Lease: уведомление о подключении новых устройств в локальной сети.

### 4. 🛑 Модуль 4: Brute-Force & Port-Scan Defense
* **Каскадная защита от подбора паролей:** обратный порядок стадий (`Stage-3 -> Stage-2 -> Stage-1`) для исключения ложных мгновенных банов на первой попытке.
* **Port Scan Detection (PSD):** аппаратный анализ сканирования портов Nmap/Masscan.
* **Порты-ловушки (Honeypots):** мгновенный 24-часовой бан при попытке стука в закрытые служебные порты (21, 23, 445, 3389 и др.).
* **Защита администратора (Whitelist Bypass):** правило возврата для `TRUSTED-MGMT` гарантирует, что доверенные адреса никогда не попадут в бан.
* **Автономные Jump-правила:** возможность экспортировать модуль отдельно для подключения к существующему фаерволу на работающем роутере.

### 5. 🔒 Модуль 5: Харденинг L2 и Защищенный DNS (DoH)
* **Изоляция MNDP / CDP / LLDP:** сокрытие роутера от провайдера и соседей по L2.
* **Безопасность MAC-Server:** ограничение MAC-Winbox и MAC-Telnet только списком `Management`, отключение `mac-ping`.
* **Харденинг `/ip service`:** отключение уязвимых служб (telnet, ftp, www, api) и привязка Winbox/SSH к списку подсетей.
* **NTP & Часовой пояс:** синхронизация точного времени с серверами `pool.ntp.org`, `time.google.com`, `time.cloudflare.com`.
* **DNS over HTTPS (DoH):** шифрование DNS через Cloudflare, Google или Quad9 со статическими bootstrap-записями и корневыми сертификатами RouterOS v7.
* **DNS Redirection:** принудительный перехват всех исходящих запросов UDP/TCP 53 в локальный DoH.

## 🎛 Модульное управление

В верхней панели генератора доступны чекбоксы для гибкого управления составом скрипта:
* **Кнопка «Все»:** генерация полного боевого скрипта.
* **Кнопка «Только активная вкладка»:** быстрый выбор одного конкретного модуля.
* **Кнопка «⚡ Только этот модуль»** внутри каждой вкладки: изолированный экспорт выбранного раздела.
