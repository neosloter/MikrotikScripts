Модуль WireGuard Server (RouterOS v7): Поддержка двух типов настроек: 1) Клиентский доступ (ПК, смартфоны с выгрузкой .conf и клиентские роутеры MikroTik с экспортом .rsc); 2) Site-to-Site (объединение офисов и подсетей LAN-to-LAN с генерацией скриптов для роутеров филиалов).

Адрес для подключения клиентов и филиалов
Адрес роутера внутри VPN сети
Сеть офиса для маршрутизации клиентам и филиалам

2. Оптимизация сети и фаервола для WireGuard

3. Настройка 1: Клиентский доступ (RoadWarrior)

Для удаленных сотрудников (ПК, смартфоны) и клиентских роутеров MikroTik (с генерацией .conf и RouterOS .rsc)

4. Настройка 2: Объединение сетей Site-to-Site (Филиалы MikroTik)

Объединение локальных сетей между роутерами (LAN-to-LAN маршрутизация и экспорт полного .rsc скрипта для филиала)

Модуль защиты от сканирования и брутфорса: Построен по архитектуре каскадных адрес-листов (vasilevkirill.ru), аппаратного PSD (Port Scan Detection) и портов-ловушек (Honeypot). При обнаружении атаки хост заносится в Blacklist и немедленно отбрасывается в таблице RAW без нагрузки на процессор и RAM.

1. Каскадная защита от подбора паролей (Brute-Force)

SSH, Winbox, Web управления

2. Детекция сканирования портов (Port Scan Detection - PSD)

21 вес, задержка 3s, низкие порты весят 3, высокие 1

3. Порты-ловушки (Port Honeypots)

Заведомо неиспользуемые порты. Любое обращение к ним расценивается как автоматическое сканирование.

Telnet, SMB, RDP, VNC, SQL, Proxy

4. Точки перехвата трафика (Правила Jump)

5. Интеграция с мониторингом и Telegram
