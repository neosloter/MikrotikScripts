# MikroTik RouterOS CHR Installer

Скрипт для быстрой установки **MikroTik RouterOS Cloud Hosted Router (CHR)** на Linux VDS/VPS (Debian, Ubuntu, CentOS, AlmaLinux, Rocky Linux, Arch Linux).

### Особенности
- **Универсальная настройка сети**:
  - Автоматическое определение текущих сетевых параметров (IP-адрес, маска подсети / CIDR, шлюз по умолчанию, DNS).
  - Поддержка **Static IP** для любых типов сетей:
    - Стандартные подсети (`/24`, `/16` и др.).
    - Point-to-Point `/32` сети с отдельным шлюзом (Hetzner Cloud со шлюзом `10.0.0.1`, OVH и др.).
  - Поддержка режима **DHCP Client**.
- **Сводка предстоящих настроек**: перед выполнением любых действий скрипт выводит подробную таблицу всех планируемых параметров (версия RouterOS, диск, сетевые реквизиты, открытые порты) и запрашивает явное подтверждение (`Y`).
- **Безопасность и управление доступом**:
  - Запрос пароля `admin` с повторным подтверждением (защита от опечаток).
  - Выбор сохранения доступа по **SSH (порт 22)** или его отключения.
  - По умолчанию всегда включен доступ через **WinBox (порт 8291)**.
  - Отключение уязвимых служб (`telnet`, `ftp`, `www`, `api`, `api-ssl`).
- **Поддержка UEFI и BIOS**: автоматическое определение режима загрузки и конвертация образа для UEFI при необходимости.
- **Выбор версии RouterOS**: по умолчанию определяется актуальная стабильная версия RouterOS v7.
- **Поддержка контейнеров**: автоматическая загрузка и включение пакета `container`.

## Быстрый запуск

Запустите команду на вашем сервере под пользователем `root`:

```bash
wget -qO chr.sh https://raw.githubusercontent.com/neosloter/MikrotikScripts/main/chr-install/chr.sh && bash chr.sh
```

или через `curl`:

```bash
curl -sSL https://raw.githubusercontent.com/neosloter/MikrotikScripts/main/chr-install/chr.sh -o chr.sh && bash chr.sh
```

## Процесс установки

1. **Проверка зависимостей**: скрипт проверяет наличие `wget`, `gunzip`, `fdisk`, `lsblk`, `ip`, `losetup`, `dd`, `awk`.
2. **Параметры системы**:
   - Выбор версии RouterOS (Enter для версии по умолчанию).
   - Ввод и подтверждение пароля администратора `admin`.
   - Запрос на сохранение доступа по SSH (порт 22).
3. **Настройка сети**:
   - Скрипт определяет текущий сетевой интерфейс, IP, маску CIDR, шлюз и DNS.
   - Предлагает выбрать режим (**1: Static IP** или **2: DHCP**).
   - При выборе Static IP предлагает подтвердить или скорректировать IP/CIDR, Gateway и DNS.
4. **Выбор диска**:
   - Автоматически находит целевой системный диск (исключая loop, zram, cd-rom).
5. **Вывод предстоящих настроек**:
   - Отображается информационная панель со всеми выбранными параметрами.
   - Запрашивается подтверждение (`Y`).
6. **Установка**:
   - Скачивается и распаковывается образ CHR и пакет container.
   - При необходимости выполняется конвертация для UEFI.
   - Образ монтируется, в `/rw/autorun.scr` прописываются настройки сети, пароль и службы.
   - Образ записывается на диск через `dd`.
7. **Завершение**:
   - Выводятся итоговые реквизиты для подключения (IP, логин, порты).
   - Сервер автоматически перезагружается через SysRq в RouterOS CHR.

---

> [!WARNING]
> Установка **полностью уничтожит все существующие данные** на целевом диске сервера! Обязательно сохраните нужные файлы перед запуском.
